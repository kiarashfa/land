KiarashFaRound 02 · Object study

An object
for every project.

Each project gets a sculpture made for it, not a copy of its icon. These are first drafts, modelled entirely in code so they can be restyled in gold, chrome, paper or lacquer by whichever world they live in. Each project's own round will refine its piece. Flagships are drawn larger.
